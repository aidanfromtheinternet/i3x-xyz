# General
Clone this repository
```shell
git clone https://github.com/aidanfromtheinternet/i3x-xyz.git
```
Then install [`live-server`](https://www.npmjs.com/package/live-server) with [`npm`](https://www.npmjs.com/) or [`bun`](https://bun.sh/) *optional*
```shell
npm install -g live-server
# or
bun install -g live-server
```
Now, start a localhost development server
```shell
cd i3x-xyz
live-server
```
And make your changes.
# My workflow
I use a mixture of terminal tools, mainly
[Fresh](https://getfresh.dev/) *- TUI IDE,*
[Xplr](https://xplr.dev/) *- to get file paths `xplr | wl-copy`,*
[Chafa](https://hpjansson.org/chafa/) *- to preview images in a kitty graphics compatible terminal,*
[ImageMagick](https://imagemagick.org/) *- to convert and apply filters to images,*
[Glow](https://github.com/charmbracelet/glow) or [md-tui](https://github.com/henriklovhaug/md-tui) *- to preview markdown files,*
[lsd](https://github.com/lsd-rs/lsd) *- better ls command,*
and many more.
